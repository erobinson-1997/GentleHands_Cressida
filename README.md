# GentleHands_Cressida
This is a car mod for Assetto Corsa based on my 1989 Toyota Cressida.
[Download Here](https://github.com/erobinson-1997/GentleHands_Cressida/releases)

## Requirements
- [Content Manager](https://assettocorsa.club/content-manager.html) and Custom Shaders Patch are recommended.

<img width="1388" height="800" alt="image" src="https://github.com/user-attachments/assets/75cf3e86-93e7-456e-8de7-71fc4607744e" />


## Known issues / notes
- Power and torque figures are estimates, not measured dyno numbers.
- Top speed and acceleration in the car's info screen are not filled in yet.
